# Data Analysis Process

This repository documents the complete data analysis workflow, from data collection and extraction to cleaning, transformation, and exploratory analysis using Python.

The notebooks and datasets cover practical data analysis tasks involving CSV, Excel, JSON, SQL databases, APIs, and web scraping.

## Overview

The goal of this repository is to build a strong foundation in data analysis by working with real-world datasets and data sources. The projects demonstrate the process of acquiring, cleaning, transforming, and analyzing data before it is used for visualization or machine learning.
